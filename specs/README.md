# specs/

Carpeta de **spec-kit**: por cada feature/Epic se persiste aquí su
`spec.md` (qué y por qué), `plan.md` (cómo), y `tasks.md` (tareas),
generados en ese orden por los slash commands `specify` → `plan` →
`tasks` → `implement`.

Cada feature vive en su propia subcarpeta: `/specs/<feature>/`. Hasta que
no se desarrolle una feature, su carpeta no existe (ver el flujo completo
en el README raíz, sección "Flujo de trabajo").
