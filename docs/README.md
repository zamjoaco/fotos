# docs/

Documentación **complementaria del proyecto** que no es código: notas de
arquitectura, decisiones (ADRs), guías de desarrollo, troubleshooting del
entorno local, etc.

Aquí NO van las specs de features — esas van en `/specs/<feature>/`
(generadas por spec-kit). Esta carpeta queda trackeada en git como
cualquier otra parte del repo.
